pymana
======

A small command-line tool to help design Magic: The Gathering manabases.
It enumerates combinations of lands (basics, duals, triomes, surveil lands, and fetchlands)
and scores them by how many "fetchable" sources they provide for each color.

This README is written for users who may be new to the command line.

Quick summary
-------------
- Input: how many fetchlands you plan to use, how many of each land type (basic, dual, surveil, triome), and how many color sources you need.
- Output: one or more candidate manabases with a score showing how many fetchable sources each gives.

Installation
------------
0. Make sure you have a recent [Python](https://www.python.org/downloads/) installed.
1. Open a terminal (Command Prompt or PowerShell).
2. In the project folder run:
   python -m pip install .
3. Then run: python -m pymana --help

Basic usage
-----------
Run pymana with the required --fetches flag and other options. Example:

`python -m pymana --fetches 4 --basic 0 --dual 4 --surveil 0 --triome 0 -u 4 -b 4 -r 0 -g 0 -w 0`

What the flags mean
-------------------
- --fetches (required): number of fetchlands you will use (e.g., 4)
- --basic, --dual, --surveil, --triome: how many of each land "type" you want in the non-fetch part of the manabase
- --max-copies: maximum copies allowed of any single non-fetch land (default 4)

Color source flags (short forms):
- -u: blue sources (U)
- -b: black sources (B)
- -r: red sources (R)
- -g: green sources (G)
- -w: white sources (W)

Tapped/untapped constraints (minimums):
- -uu, -ub, -ur, -ug, -uw : minimum number of untapped sources for each color
- -tu, -tb, -tr, -tg, -tw : minimum number of tapped sources for each color

Per-land limits
---------------
You may also use options like --underground_sea, --island, --mountain, etc., to set a max for a specific named land. The option name is the land name lowercased with spaces replaced by underscores.

Important consistency rules
--------------------------
The program enforces a few math checks and will abort with a message if they fail:
- The color source counts must add up correctly:
  w + u + b + r + g == 2 * (dual + surveil) + basic
  (This ensures requested "pips" match the number of non-fetch lands you asked for.)
- For each color, tapped + untapped cannot exceed the total sources for that color.

If you see an error like "Mana sources must add up to ..." adjust the basic/dual/surveil/triome numbers or the -u/-b/-r/-g/-w counts so the arithmetic holds.

Understanding the output
------------------------
- For each candidate solution the tool prints:
  - Score: a percentage indicating how well the non-fetch lands plus the chosen fetches provide "fetchable" sources.
  - A comma-separated list of lands and how many copies of each are used.
  - A per-fetch summary showing how many sources each fetch can reach in that solution.

Examples for beginners
----------------------
1) Very small example (4 fetches, 4 duals, blue/black):
   `python -m pymana --fetches 4 --basic 0 --dual 4 --surveil 0 --triome 0 -u 4 -b 4 -r 0 -g 0 -w 0`

2) Add basic lands and require at least one untapped blue source:
   `python -m pymana --fetches 4 --basic 2 --dual 3 --surveil 0 --triome 0 -u 5 -b 3 -r 0 -g 0 -w 0 -uu 1`

Tips and troubleshooting
------------------------
- If you get "No solutions found", try loosening per-land maximums (--<land> flags), lower color constraints, or change the mix of basic/dual/triome/surveil counts.
- Use --max-copies to restrict repetition of a single land (default is 4).
- Run python -m pymana --help to see the full list of flags and the exact per-land names accepted.

Further notes
-------------
- This tool considers a fixed catalogue of lands (fetches, a set of duals, triomes, surveil lands, and basics). If you want to modify those lists you'll need to edit the source (src\pymana\pymana.py).
- Designed for generating possible manabases to inspect manually, not to automatically mutate or persist changes.
